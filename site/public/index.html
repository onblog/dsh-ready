常见问题

要钱吗？

DSH 就位本身免费开源（AGPL-3.0-only）。个人使用、学习、二次开发都不要钱；如果你要在闭源商业产品里使用，需要一份商业授权。

它是 DeepSeek 官方项目吗？

不是。它是社区做的第三方桌面壳，只负责安装、启动、升级官方 DSH，不修改 DSH 本体，也不替代它的 Web 界面。

会收集我的数据吗？

官网只记录匿名设备数与下载次数，用来告诉你「有多少人在用」。不写 IP、不写设备指纹、不设 Cookie，也没有任何第三方统计脚本。桌面应用本身不上报任何数据。

为什么打开时被系统拦住了？

目前安装包没有购买苹果与微软的开发者签名。macOS 上右键图标选「打开」，Windows 上点「更多信息 → 仍要运行」即可，之后不会再拦。

我已经在终端里装过 DSH 了，还用吗？

可以直接用：DSH 就位会优先复用系统里已装的 DSH，只负责帮你启停、看日志、升级，不会重复安装。

首次打开需要允许一次

安装包已下载完成。它不是从 App Store 安装的，macOS 第一次会拦下它——这是正常现象，放行一次即可。

  1. 双击打开 App，看到「未打开 “DSH 就位.app”」的提示时，点「完成」。
  2. 打开「系统设置 → 隐私与安全性」，在「安全性」区域找到被阻止的 App，点「仍要打开」。
  3. 输入 Mac 密码或使用触控 ID，之后就能正常双击打开。

如果系统提示「已损坏」，在「终端」里执行一次下面的命令：

sudo xattr -cr "/Applications/DSH 就位.app"
